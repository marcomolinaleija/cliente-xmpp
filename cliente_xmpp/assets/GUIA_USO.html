Primeros pasos y conexión

  1. Elige el Tipo de conexión: el puente local instalado en tu equipo o un servidor XMPP.
  2. Escribe tu JID y contraseña. El servidor puede quedar vacío si tu JID lo resuelve automáticamente.
  3. Usa Conectar. Puedes marcar Recordar contraseña; entonces también podrás activar Conectar automáticamente.

Al conectar por primera vez, el panel de vinculación mostrará Generar QR. Abre WhatsApp en tu teléfono, entra a los dispositivos vinculados y escanea el código. Cuando el puente ofrezca vinculación por número, sigue las instrucciones del diálogo y copia el código si lo necesitas.

Consejo: el QR tiene una cuenta regresiva. Si vence, usa Generar nuevo QR. Cerrar el diálogo no borra un QR que aún sea válido.

Desde Cuenta > Conexión > Desconectar esta ventana puedes cortar la conexión de esta aplicación sin desvincular WhatsApp ni borrar tus chats. Cuenta > Salir cierra la aplicación.

Lista de chats y búsqueda

La pantalla principal muestra los chats con actividad. Las conversaciones se ordenan por novedad; los chats fijados quedan arriba.

  • Escribe en Buscar para encontrar contactos, números y mensajes. Pulsa Enter para abrir el resultado elegido.
  • Usa Nuevo chat para escribir un número. Elige el país o pega un número internacional que empiece con + o 00.
  • Selecciona un chat y pulsa Enter o haz doble clic para abrirlo.
  • En la lista, pulsa F2 para cambiar el nombre local del chat. No modifica el nombre en WhatsApp.
  • Con el menú contextual del chat puedes silenciarlo, fijarlo o eliminar su contenido local.
  • Marcar todos como leídos limpia los indicadores de chats no leídos y sincroniza esa lectura en segundo plano.
Eliminar chat borra el historial local y las descargas de ese chat en este equipo. No elimina la conversación de WhatsApp ni mensajes en otros dispositivos.

Leer y escribir en una conversación

Historial

Al abrir un chat se muestra primero la caché local y después se actualiza el historial. Usa Cargar mensajes anteriores para recuperar páginas más antiguas. Cada petición manual carga hasta 100 mensajes desde la caché y, si hace falta, desde el servidor.

Dentro de la lista de mensajes, Inicio también va al primer elemento visible y solicita otra página anterior. Repite la tecla o usa el botón hasta llegar a la fecha que buscas. Si el chat tiene muchísimos mensajes de un mismo día, puede seguir anunciando la misma fecha aunque ya haya añadido mensajes más antiguos de ese día.

  • Pulsa Enter sobre un mensaje para leerlo completo en una ventana.
  • Si aparece Ir a mensaje citado, actívalo para saltar al mensaje original.
  • Pulsa Esc para volver a la lista de chats. Si estabas respondiendo, editando o grabando, Esc cancela primero esa acción.

Enviar texto, archivos y audio

  • Escribe en el cuadro de mensaje y pulsa Enter para enviar.
  • Usa Mayús+Enter para insertar una nueva línea sin enviar.
  • Con el cuadro vacío, el botón principal se llama Grabar audio. Púlsalo para iniciar; después puedes pausar, cancelar o detener y enviar. La casilla Audio de una sola escucha se muestra mientras grabas.
  • Adjuntar permite enviar archivos. También puedes usar Ctrl+V para adjuntar archivos o una imagen copiada del portapapeles.
  • Enviar sticker permite elegir una imagen para mandarla como sticker.
  • Con Ctrl+Flecha arriba, en un cuadro de texto vacío, puedes editar tu último mensaje de texto si todavía está dentro del tiempo permitido. Pulsa Esc para cancelar la edición.

Acciones sobre un mensaje

Selecciona un mensaje y abre su menú contextual con clic derecho o la tecla de menú de tu teclado. Las opciones cambian según el tipo de mensaje y tus permisos.

  • Responder: prepara una respuesta con cita. En grupos, también puede aparecer Responder en privado o Enviar mensaje privado cuando se conoce la identidad del participante.
  • Copiar texto o Copiar enlace: copia el contenido útil al portapapeles.
  • Reenviar: permite elegir otro chat de destino.
  • Reaccionar: elige entre 👍, ❤️, 😂, 😮, 😢 o 🙏. En Más reacciones... puedes buscar por nombre o escribir un emoji compatible con WhatsApp.
  • Cuando alguien reacciona a tu último mensaje, la lista de chats lo resume, por ejemplo: Ari reaccionó a «Nos vemos» con ❤️.
  • Destacar: guarda el mensaje para localizarlo desde la información del chat.
  • Editar mensaje: disponible sólo en mensajes de texto tuyos que aún se pueden editar.
  • Eliminar mensaje: solicita eliminar un mensaje propio para todos; la aplicación pide confirmación.
  • En fotos, videos, stickers y archivos puedes descargar, abrir, copiar el archivo o, cuando corresponda, describirlo con RayoAI. En un álbum completo puede aparecer Guardar álbum.

Para audios seleccionados: Espacio reproduce o pausa, S cambia la velocidad, y Alt+Flecha izquierda / Alt+Flecha derecha retrocede o adelanta cinco por ciento. La velocidad elegida se conserva para próximas reproducciones.

Para abrir el enlace del mensaje enfocado, pulsa L. Si hay un mensaje de texto seleccionado, Flecha izquierda lo lee con el lector integrado.

Grupos, menciones y encuestas

Mencionar a una persona

En un grupo escribe @ y parte del nombre. Se abrirá una lista de sugerencias. Usa Flecha arriba y Flecha abajo para elegir; confirma con Tab o Enter. La aplicación envía una mención real de WhatsApp, no sólo texto.

Encuestas

Al seleccionar una encuesta verás Votar en encuesta. El menú contextual también permite votar y ver resultados. Los cambios de voto y resultados se actualizan cuando llegan desde WhatsApp.

En la información de un grupo puedes consultar participantes, archivos, mensajes destacados y estadísticas locales. Los nombres mostrados intentan respetar el nombre que tienes guardado para cada persona.

Información del contacto, destacados y archivos

Dentro de un chat, activa el botón con el nombre del contacto o grupo para abrir su información. Ahí puedes consultar el número, el estado disponible, participantes del grupo y, si existe, la foto de perfil.

  • Ver mensajes destacados: muestra los mensajes que marcaste como destacados. Elige uno y usa Ir al mensaje.
  • Buscar o Ctrl+Mayús+F: busca sólo en ese chat. Puedes combinar texto con un filtro por fecha y saltar al resultado.
  • Ver archivos: separa todos los elementos en archivos, enlaces, fotos, videos, audios y stickers. Desde ahí puedes abrir, copiar o borrar una descarga local.
  • Estadísticas locales del chat: muestra actividad, participación, horarios y otros resúmenes basados en los mensajes guardados aquí.
  • Describir foto con RayoAI: disponible cuando la foto de perfil está descargada y RayoAI está configurado.

Configuración, estadísticas y almacenamiento

Configuración

Abre Configuración desde el encabezado. Puedes elegir el tipo de conexión que se usará en el próximo inicio, controlar notificaciones de Windows, ocultar su vista previa, activar anuncios con NVDA y decidir si suenan los mensajes del chat abierto o los mensajes enviados.

También puedes elegir si Alt+F4 minimiza la aplicación a la bandeja del sistema. Si la minimizas, usa el icono de WhatsApp CAN en la bandeja para mostrarla de nuevo.

En la aplicación instalada, la sección de actualizaciones permite elegir la frecuencia de búsqueda, desactivarla o usar Buscar actualizaciones ahora.

Estadísticas generales

Ve a Ver > Estadísticas para consultar resúmenes, actividad diaria, chats y conversaciones sin respuesta. Puedes elegir períodos de 7, 30 o 90 días, o todo el historial local, y filtrar contactos o grupos.

Las estadísticas y la tendencia emocional se calculan en este equipo usando los mensajes almacenados. Son una aproximación basada en palabras, emojis, negaciones e intensificadores; no comprende por completo el contexto, la ironía ni el sarcasmo.

Gestor de almacenamiento

Abre Ver > Gestor de almacenamiento para saber cuánto ocupan descargas, grabaciones, cachés y la base local. Puedes actualizar el cálculo, marcar archivos concretos y borrarlos. En sus listas, Espacio marca o desmarca el elemento enfocado y Ctrl+A marca todos los elementos eliminables.

Borrar todos los datos elimina de forma irreversible la configuración, credenciales, base local y archivos de WhatsApp CAN en este equipo; exige dos confirmaciones y cierra la aplicación. Exporta o conserva lo importante antes de usarlo.

Preguntas frecuentes

¿Por qué no veo mensajes muy antiguos?

El cliente abre primero una cantidad limitada de mensajes para mantenerse ágil. Usa Cargar mensajes anteriores o Inicio. Las páginas locales se muestran primero y luego se pide el resto al servidor.

¿Por qué un archivo dice Descargar?

El mensaje está disponible, pero su copia local todavía no se ha bajado. Activa Descargar o Abrir para obtenerla. Después podrás copiarla o abrirla desde el gestor de archivos del chat.

¿Qué ocurre si leo un chat desde el teléfono?

Cuando WhatsApp y el puente informan la lectura, el cliente actualiza los indicadores. Puede tomar un momento según la conexión.

¿La guía necesita internet?

No. Esta página está incluida en WhatsApp CAN y se abre en tu navegador predeterminado.
