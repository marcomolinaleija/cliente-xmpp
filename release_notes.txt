WhatsApp CAN 1.3.0

Puente local opcional para Windows
- El instalador pregunta cómo quieres usar WhatsApp CAN: con un puente local en WSL2 o con un
  servidor XMPP/VPS.
- Si eliges el modo local, descarga el appliance oficial desde una release inmutable, comprueba su
  SHA-256 y configura Prosody, Slidge WhatsApp v14 y adjuntos exclusivamente en 127.0.0.1.
- El instalador del cliente sigue siendo ligero: el appliance de aproximadamente 688 MiB sólo se
  descarga cuando eliges el puente local.
- La instalación local se puede reanudar de forma segura si Windows o la red interrumpen el proceso.

Cliente híbrido
- Los perfiles local y remoto se guardan por separado. Puedes seguir usando tu VPS y cambiar de
  perfil desde la pantalla de conexión o desde Configuración.
- Las credenciales locales pasan al almacén seguro de Windows y la CA privada del appliance se fija
  para validar STARTTLS sin confiar en certificados de terceros.
- El cliente inicia y comprueba el puente fuera del hilo de interfaz, muestra estados claros durante
  el arranque y evita ofrecer el QR antes de que Slidge termine de autenticarse con Prosody.

Puente WhatsApp v14
- Corrige la carrera de presencias que podía reiniciar Slidge durante una renovación simultánea.
- Conserva las mejoras anteriores del puente para menciones, reenvíos, stickers, notas de voz,
  sincronización de leídos, nombres de contactos y alias mexicanos.
